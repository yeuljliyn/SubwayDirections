# SubwayDirections

C++로 구현한 지하철 최단 경로 탐색 프로그램입니다.

출발역과 도착역을 입력하면 지하철 노선 정보를 기반으로 최단 경로를 탐색하고,
이동 경로와 총 소요 시간을 출력합니다.

## 주요 기능

- 1~6호선 지하철 노선 데이터 관리
- CSV 파일을 통한 역 및 구간 소요 시간 데이터 로드
- 출발역 및 도착역 입력
- 존재하지 않는 역 입력에 대한 유효성 검사
- 다익스트라 알고리즘을 이용한 최단 경로 탐색
- 환승역 연결 및 환승 시간 3분 적용
- 최단 이동 경로 출력
- 총 소요 시간을 분/초 단위로 출력

## 실행 예시

```text
출발 역 : 홍대입구
도착 역 : 광화문

[탐색 결과]
홍대입구 -> 광화문
이동경로: 홍대입구 -> 신촌 -> 이대 -> 아현 -> 충정로(환승) -> 서대문 -> 광화문
총 소요 시간: 12분 50초
